# TasksOrder: редизайн екранів «Сьогодні», «План», «Завдання»

Специфікація для імплементації на Flutter (Material 3).
Канонічне джерело візуалу: полотно дизайну (посилання нижче) і файли з `mockups/`.
Якщо щось у цьому документі розходиться з макетами, перевага за макетами, а питання слід передати автору.

- Полотно: https://claude.ai/artifact/GCRk5PKnYE2U2phvtk2Y3p (рядок «TasksOrder · Сьогодні, План, Завдання»)
- Застосунок зараз: https://valeriyh.github.io/TasksOrder (Flutter web, Drift)

## Обсяг

1. Переробити вигляд трьох вкладок: **Сьогодні**, **План**, **Завдання**.
2. Підтримати **світлу й темну** тему (перемикання за системною або налаштуванням застосунку).
3. Логіку планування, місткості, повторів і фокусу **не змінювати**. Змінюється лише подання.
4. Нижня навігація, FAB і екран редагування задачі лишаються функціонально тими самими. Їхній стиль підлаштувати під палітру з токенів.

## Мова

Інтерфейс подано українською (рядки з макетів). Використовуй наявну локалізацію застосунку (`AppLocalizations`). Нові рядки додавай у ARB для всіх мов, які вже є.

Нові рядки (українською → пропозиція англійською):

| Ключ (пропозиція) | uk | en |
|---|---|---|
| `doneButton` | Готово | Done |
| `completedButton` | Виконано | Completed |
| `progressOf` | {done} з {total} | {done} of {total} |
| `noDueDate` | Без терміну | No due date |
| `dayOff` | вихідний | day off |
| `freeSlots` | Вільно: {n} місце/місця/місць (plural) | {n} slot(s) free |
| `activeCount` | {n} активне/активні/активних (plural) | {n} active |

Назви пріоритетів у макетах: Критичний, Високий, **Звичайний**, Низький, **Колись**. Якщо в ARB уже є інші переклади, лиши наявні.

## Спільні компоненти

### TaskCard (ядро всіх трьох екранів)

```
┌──────────────────────────────────────────┐
│ [● Високий] [📌 Закріплено] [↻ Щомісяця]  │  ← рядок чипів, Wrap, spacing 6
│ Оплатити комунальні послуги              │  ← назва, 17/w700
│ 🕑 Прострочено на 2 дні      [✓ Готово]   │  ← термін зліва, кнопка справа
└──────────────────────────────────────────┘
```

- Контейнер: radius 18, padding `fromLTRB(16, 14, 14, 12)`, вертикальний gap 10.
- Фон `card`. У світлій темі є тінь (2 шари, див. токени), у темній тіні немає.
- Відстань між картками 10, горизонтальні поля списку 16.

**Чипи** (висота 24, radius 12, padding по горизонталі 10, іконка 12, gap 5). Порядок:

1. **Пріоритет**: завжди. Крапка 8×8 кольору тексту + мітка.
2. **Фокус** (`focusedAt != null`): на «Плані» й «Завданнях». На «Сьогодні» не показується, бо там є окрема секція «Фокус». Стиль `accentChip`.
3. **Закріплено** (`pinnedDate != null`): стиль `accentChip`.
4. **Повтор** (`recurrence != null`): текст із правила повтору («Щодня», «Пн, Ср, Пт», «Щомісяця», «Кожні 3 дні»). Стиль `neutralChip`.
5. **Заплановано на {дата}**:
   - «Завдання»: завжди («Заплановано на сьогодні», «Заплановано на пн, 16 лист.», «Пізніше»);
   - «Сьогодні»: лише для задач фокусу, запланованих не на сьогодні.
   Стиль `neutralChip`.
6. **Понад план** (задача понад місткість дня, рядок `Extra` у коді): лише на «Плані». Стиль `extraChip` (бурштиновий).

**Рядок терміну:** іконка `schedule` 14 + текст 13/w600, колір `muted`. Прострочена задача має колір `alert` («Прострочено на N днів»). Немає терміну: «Без терміну».

**Кнопка виконання** (замість чекбокса):

- Висота 40, minWidth 116, radius 20, текст 14/w700, іконка `check` 16.
- Не виконано: «Готово», обведення 1.5 кольору `accent`, прозорий фон, текст `accent`.
- Виконано: «Виконано», фон `doneButtonBg`, текст `doneButtonFg`, без обведення.
- Повторне натискання повертає задачу (undo).
- Семантика: `Semantics(button: true, toggled: isDone, label: markDoneA11y/markUndoneA11y)`.
- Мінімальна зона натискання 44.

**Стан «виконано»:** уся картка opacity 0.62 (анімація 200 мс), назва перекреслена кольором `titleDone`, картка переїжджає в кінець своєї групи. Виконані сьогодні задачі лишаються на екрані до кінця дня.

### Заголовок секції (Сьогодні)

Іконка 16 + назва UPPERCASE + праворуч `виконано/усього` у секції (13/w600), колір `muted`. Padding зверху 12, зліва 4.

- «Фокус»: іконка фокусу.
- «Заплановано»: іконка `today_outlined`. **Не шпилька**: у цій групі є і звичайні, і закріплені, і повторювані задачі.

## Екран «Сьогодні»

Порядок зверху вниз:

1. Безпечний відступ + padding `fromLTRB(20, 8, 20, 14)`.
2. Повна дата («Неділя, 15 листопада»), 14/w500, `muted`.
3. «Сьогодні», 34/w800.
4. Рядок прогресу (відступ 14):
   - смуга висотою 8, radius 4, фон `track`;
   - заповнення кольором `accent`, ширина = done / total, анімація 300 мс;
   - праворуч текст «{done} з {total}», 14/w700.

   `total` = усі задачі на екрані сьогодні (фокус + заплановані, включно з виконаними сьогодні). `done` = виконані сьогодні з них.
5. Секція **Фокус**: усі задачі з `focusedAt != null`.
6. Секція **Заплановано**: задачі, які застосунок поставив на сьогодні (автоматично або через `pinnedDate`).
7. Порожній стан і банер перевантаження («Більше, ніж заплановано…») лишаються з наявної логіки, у стилі нової палітри: банер з фоном `capOverBg` і текстом `capOverFg`.

Знизу списку padding ≥ 168, щоб FAB і NavigationBar не перекривали останню картку.

## Екран «План»

1. Підзаголовок: діапазон днів («15 – 21 листопада»). Заголовок «План».
2. Для кожного дня в горизонті планування:
   - **Рядок дня** (minHeight 44):
     - зліва назва: «Сьогодні», «Завтра» або «Вт, 17 листопада», 17/w700;
     - у «Сьогодні» перед назвою іконка `today_outlined` кольору `accent`, а сама назва кольору `todayName`;
     - якщо день позначений вихідним (місткість 0 за налаштуваннями), після назви сірим « · вихідний»;
     - справа **CapacityPill**;
     - далі кнопка `tune` 44×44: відкриває наявний діалог місткості дня.
   - **CapacityPill**:
     - висота 28, radius 14, текст 13/w700 «{заплановано}/{місткість}»;
     - звичайний стан: фон `capPillBg`, текст `capPillFg`; перед текстом ряд крапок 6×6 з gap 3, по одній на кожне місце місткості; зайняті крапки кольору `accent`, вільні `dotOff`;
     - перевантаження (заплановано > місткості): фон `capOverBg`, текст `capOverFg`, замість крапок іконка `error_outline` 14.
   - **Картки** задач цього дня.
   - **Вільні місця** (якщо місткість > заплановано):
     - пунктирний прямокутник: висота 48, radius 14, рамка 1.5 dashed `freeBorder`;
     - по центру «Вільно: N місце/місця/місць», 13/w600, `muted`;
     - необов'язково: натискання може відкривати додавання задачі на цей день.
3. Відступ між днями: 6 + padding зверху 10.

## Екран «Завдання»

1. Над заголовком «{n} активних» (кількість невиконаних, з плюралізацією). Заголовок «Завдання». Праворуч `IconButton` кошика 44×44.
2. **Фільтри**: горизонтальний скрол, padding `fromLTRB(16, 16, 16, 12)`, gap 8. Порядок: Усі, Фокус, З терміном, Регулярні, Пізніше.
   - Чип: висота 40, radius 12, padding 14, текст 14/w600.
   - Вибраний: фон `filterOnBg`, текст `filterOnFg`, без рамки, з іконкою `check` 16.
   - Невибраний: рамка 1 `filterOffBorder`, текст `filterOffFg`.
   - Після мітки лічильник активних задач для цього фільтра, 12/w700 (`filterCountOn` або `filterCountOff`).
   - Можна використати `FilterChip` або `ChoiceChip` з кастомною темою.
3. Список карток відповідно до фільтра. На кожній картці є чип «Заплановано на …».
4. Порожній результат: по центру іконка `checklist` 40 і «Тут поки порожньо», колір `muted`.

## Навігація і FAB

- `NavigationBar` висотою 80: фон `navBg`, індикатор `navIndicator` (64×32, radius 16). Активна мітка 12/w700 кольору `navActive`, неактивні 12/w500 кольору `navIdle`.
- FAB (на «Сьогодні» і «Завданнях»): 56×56, radius 16, фон `fabBg`, іконка `fabFg`. Положення стандартне, над NavigationBar.

## Доступність

- Мінімальні зони натискання 44×44: кнопки «Готово», `tune`, кошик, фільтри (40 по висоті + відступи).
- Контраст тексту ≥ 4.5:1 в обох темах. Палітра підібрана під це, тож не роби кольори тексту світлішими.
- Пріоритет не передається лише кольором (є мітка).
- Прогрес: `Semantics(value: '{done} з {total}')`.

## Мапінг на модель даних (з наявного коду)

| UI | Поле / умова |
|---|---|
| Секція «Фокус», чип «Фокус» | `focusedAt != null` |
| Чип «Закріплено» | `pinnedDate != null` |
| Чип повтору | `recurrence != null` (текст з правила) |
| «Заплановано на …» | дата, на яку задачу поставив планувальник; «Пізніше», якщо її немає в горизонті |
| «Понад план» | задача понад місткість дня (рядок `Extra`) |
| Рядок терміну, червоний | дедлайн; прострочена → `alert` |
| Виконано | `status` / `completedAt` |

## Що не входить

Екран редагування задачі, налаштування, кошик, діалог місткості. Їх лише перефарбувати за токенами, без змін структури.
