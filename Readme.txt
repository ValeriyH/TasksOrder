### Задача
Розробити програму під андроїд по пріотизаціі щоденних задач

### Необхідна функціональність
Основні ідеї (наразі без структуризаціі)
- Закидувати всі задачі без розбору, проставляючи пріоритет (від 1 до 3,5,10 - налаштовується), а також дату закінчення, якщо є
- Виставити кількість задач на день. Можливість виставити по днях. Наприклад по буднях по 1 задачі, на суботу 3, в понеділок і неділю - жодної

Програма розраховує кількість задач на день і "планує" відповідно день (і наступні дні) виставляючи задачі по пріорітетах. При додаванні нової задачі список корректується
Іноді нижній "пріорітет" може потиснути верхній, якщо підходить дата закінчення, або показувати в день не 1 (як прописано) а 2 задачі.
Задачі, що призначені на сьогодні, але не зроблені переходять в кінець черги. Так, якщо задача "заблокована" вона не буде "блокувати" інші в чезі

### Розробка
Flattern for VS code + Андроід SDK
Цикл розробки SDLC: Планування - Розбиття на задачі - Імплементація - Тестування і виправлення - Наступний крок (аналіз нових потреб або наступна задача зі списку).
Документація - обсідіан, англійска мова
